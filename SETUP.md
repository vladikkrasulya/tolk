# Tolk: установка и первая настройка

Версия 0.7.0. Обзор функций — в [README.md](README.md), работа с приложением — в [docs/USER-GUIDE.md](docs/USER-GUIDE.md).

Система состоит из трёх частей:

- **Приложение Tolk** на Mac: окна, горячие клавиши, правила, история.
- **Сервер модели перевода**: Ollama с моделью `gemma-translate`. Может стоять на этом же Mac или на другом компьютере в сети.
- **Модель подсказок** на этом Mac: нужна только для автодополнения. Её запускает сам Tolk через `llama-server`.

## Варианты установки

| Вариант | Приложение | Модель перевода | Состояние |
|---|---|---|---|
| 1. Модель в домашней сети | Tolk на Mac | Ollama на другом компьютере (Windows, Linux, Mac) | Работает, так устроено у автора |
| 2. Всё на одном Mac | Tolk на Mac | Ollama на этом же Mac | Работает, если хватает памяти (около 24 ГБ свободной) |
| 3. Модель по облачному API | Tolk на Mac | Сервис, совместимый с OpenAI | Не сделано |
| 4. Только Windows | Приложения нет | Ollama на Windows | Модель запустится, Tolk под Windows не существует |

- **Есть Mac** — вариант 1 или 2.
- **Есть только Windows** — Tolk не запустится: окна, двойное ⌘C и вставка написаны под macOS. На Windows можно поднять только модель для Mac из домашней сети.
- **Нет подходящего железа для модели** — нужен вариант 3, но в Tolk его пока нет. Не хватает поля для ключа API и ручного ввода имени модели. «Адрес вне дома» с заголовками рассчитан на Ollama за туннелем и с облачным API не проверялся.

```
 Tolk (Mac)                                Сервер модели (любой компьютер)
 ┌──────────────────────────┐   HTTP    ┌──────────────────────────────┐
 │ двойное ⌘C, окна, история │ ───────▶ │ Ollama, порт 11434            │
 │ правила и глоссарий       │ ◀─────── │ модель gemma-translate        │
 │ автодополнение:           │  перевод  └──────────────────────────────┘
 │ llama-server 127.0.0.1    │
 └──────────────────────────┘
        │ если сервер недоступен
        ▼
 запасной путь: Google, перевод Apple на устройстве или ничего
```

## Что нужно

Для приложения:
- Mac с macOS 14 или новее, Apple Silicon.
- Command Line Tools со Swift 6.2: `xcode-select --install`. Xcode не нужен.

Для модели перевода:
- Компьютер с Ollama. Файл базовой модели занимает 18,7 ГБ.
- Около 24 ГБ памяти в сумме (видеопамять плюс оперативная). Это оценка по размеру файла.
- Чем больше модели помещается в видеокарту, тем быстрее. Ориентиры по скорости генерации с `num_ctx 8192`:

| Видеопамять | Скорость | Источник |
|---|---|---|
| 6 ГБ | около 22–26 токенов в секунду, обычный текст за 2–7 с | замер на сервере автора |
| 12 ГБ | около 55 токенов в секунду | Windows-ПК, установка друга пользователя |

Для автодополнения: Homebrew и около 3,6 ГБ свободной памяти.

## Сервер модели (Ollama)

Шаги одинаковы для Windows, Linux и Mac.

1. Установите Ollama с сайта ollama.com.
2. Скачайте базовую модель:

   ```
   ollama pull gemma4:26b
   ```

3. Создайте файл `Modelfile`:

   ```
   FROM gemma4:26b
   SYSTEM You are a professional translator. Translate the user text accurately and naturally, preserving meaning, tone, formatting, code and names. Output only the translation, with no explanations.
   PARAMETER num_ctx 8192
   PARAMETER num_predict 8192
   PARAMETER temperature 0.3
   PARAMETER top_k 64
   PARAMETER top_p 0.95
   ```

4. Соберите модель:

   ```
   ollama create gemma-translate -f Modelfile
   ```

   Имя должно заканчиваться на `-translate`: в настройках Tolk в списке моделей перевода показываются только такие.

5. Если сервер стоит не на том же компьютере, что Tolk, разрешите Ollama принимать запросы из сети: переменная окружения `OLLAMA_HOST=0.0.0.0`, затем перезапуск Ollama. Откройте порт 11434 в брандмауэре только для домашней сети.
6. Необязательно: `OLLAMA_NUM_PARALLEL=2`, чтобы два запроса шли одновременно. Tolk сам не отправляет больше двух запросов сразу. Четыре слота на видеокарте 6 ГБ оказались хуже двух.
7. Проверьте с компьютера, где стоит Tolk:

   ```
   curl http://АДРЕС_СЕРВЕРА:11434/api/tags
   ```

   В ответе должна быть `gemma-translate`.

Что стоит знать:

- **Почему `num_ctx 8192`.** Замер на сервере автора: генерация около 26 ток/с против 22 ток/с с 32768 (на 15–20 % быстрее), первое слово появляется так же быстро. Для переводов и подсказок хватает 8192.
- **Запрос с другим `num_ctx` перезагружает модель.** Ollama держит один размер контекста; если запрос просит другой, модель выгружается и загружается заново (около 30 секунд). Tolk сам `num_ctx` не передаёт. Меняйте его только в `Modelfile`, не в других клиентах той же модели.
- Первый запрос после запуска или смены модели идёт долго, от 30 до 150 секунд: модель загружается в память.
- «Размышление» у модели по умолчанию включено, с ним ответ занимает около минуты. Tolk сам его отключает. Если проверять модель командой `ollama run`, будет медленно, это не поломка.
- На видеокарте 6 ГБ помещается одна большая модель. Смена модели означает перезагрузку.
- Старый вариант с `num_ctx 32768` можно оставить под другим именем, например `gemma-translate-32k`.

## Модель подсказок на Mac (автодополнение)

Нужна только если вы включаете автодополнение. Перевод, «Перевод при наборе» и быстрые действия от неё не зависят.

1. Установите `llama.cpp` через Homebrew:

   ```
   brew install llama.cpp
   ```

   Tolk ищет `llama-server` в `/opt/homebrew/bin` и `/usr/local/bin`.

2. Скачайте файл модели **Q4_K** (около 3,4 ГБ) из репозитория `huihui-ai/Huihui-gemma-4-E2B-it-qat-q4_0-unquantized-abliterated-GGUF` на Hugging Face. Нужен файл `Huihui-gemma-4-E2B-it-qat-q4_0-unquantized-abliterated-Q4_K.gguf`. Это Gemma 4 E2B: на нашем наборе из 54 случаев она не хуже E4B, а подсказка приходит за 105 мс вместо 160–250 мс.
3. Положите файл в `~/Library/Application Support/Tolk/models/`. Файл можно переименовать, например в `gemma-4-E2B-abl-Q4_K.gguf`: Tolk смотрит на расширение `.gguf`.
4. В настройках Tolk, вкладка «Автодополнение», в списке «Модель» выберите этот файл. По умолчанию в настройках записано имя `gemma-4-E4B-it-q4_0.gguf`: если такого файла нет, подсказки не запустятся, пока вы не выберете свой.
5. Включите «Автодополнение (Tab)» или пункт «Автодополнение → Включено» в меню Tolk.

Tolk запускает `llama-server` на `127.0.0.1:8178` и останавливает его, когда закрывается. Если сервер не запустился, причина видна в настройках и в меню, рядом кнопка «Повторить». Журнал сервера: `~/Library/Logs/Tolk/llama-server.log`.

## Сборка и установка Tolk

1. Получите исходный код проекта.
2. Один раз создайте локальный сертификат подписи, чтобы после пересборки не слетало разрешение «Универсальный доступ»:

   ```
   scripts/make-signing-cert.sh
   ```

   macOS может спросить пароль от учётной записи.

3. Соберите приложение:

   ```
   scripts/build-app.sh
   ```

   Получится `build/Tolk.app`. Версия берётся из файла `VERSION`.

4. Установите:

   ```
   scripts/install.sh
   ```

   Приложение попадёт в `/Applications/Tolk.app` и будет запускаться при входе в систему. Без автозапуска: `scripts/install.sh --no-autostart`. Убрать автозапуск: `launchctl bootout gui/$(id -u)/local.vk.tolk`, затем удалить `~/Library/LaunchAgents/local.vk.tolk.plist`.

5. Чтобы отдать приложение другому человеку, соберите образ: `scripts/make-dmg.sh` создаёт `build/Tolk-<версия>.dmg` с приложением и короткой инструкцией. Образ подписан самодельным сертификатом, поэтому на чужом Mac его нужно один раз открыть через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Приложение подписано самодельным сертификатом и рассчитано на сборку на своём Mac. Без сертификата `build-app.sh` подпишет приложение ad-hoc, и macOS будет сбрасывать разрешение «Универсальный доступ» после каждой пересборки.

## Разрешения macOS

Выдаются в «Системные настройки → Конфиденциальность и безопасность».

| Разрешение | Для чего |
|---|---|
| «Универсальный доступ» | Двойное ⌘C, вставка перевода, быстрые действия, автодополнение, «Перевод при наборе» |
| «Запись экрана» | Перевод области экрана (⌥⇧S), распознавание текста окна для контекста автодополнения. После выдачи перезапустите Tolk |
| «Локальная сеть» | Обращение к серверу модели на другом компьютере; запрос появится при первом обращении |

В настройках Tolk, вкладка «Общие», блок «Разрешения» показывает, есть ли «Универсальный доступ».

## Первая настройка

Откройте «Настройки» (⌘6), вкладка «Перевод»:

1. **Адрес в домашней сети.** По умолчанию стоит адрес сервера автора. Замените на свой: `http://АДРЕС:11434`, для модели на этом же Mac `http://localhost:11434`. Кнопка «Проверить соединение» покажет, отвечает ли сервер.
2. **Модель перевода:** `gemma-translate`.
3. **Запасной перевод.** По умолчанию Google: если сервер недоступен, текст уйдёт в Google. Если это нежелательно, выберите «Apple (на этом Mac)» (нужна macOS 26 и загруженные языки) или «Никакого».
4. **Языки.** Основной язык по умолчанию русский, второй английский.
5. **Профиль глоссария:** «Дом» (по умолчанию) или «Работа». Подробности ниже.

Затем при желании включите автодополнение (вкладка «Автодополнение») и проверьте горячие клавиши (вкладка «Общие»).

## Файлы и где что лежит

| Что | Где |
|---|---|
| Настройки | `~/Translate/tolk.json` (всё меняется и через окно настроек) |
| Правила профиля «Работа» | `~/Translate/rules.md` |
| Правила профиля «Дом» | `~/Translate/home.md` (если файла нет, действуют встроенные правила) |
| История переводов | `~/Library/Application Support/Tolk/history.jsonl`, права 0600, до 3000 записей |
| Статистика автодополнения | `~/Library/Application Support/Tolk/autocomplete-stats.json` (только числа) |
| Память о стиле (если включена) | `~/Library/Application Support/Tolk/style.db`, зашифрована AES-GCM |
| Ключ памяти о стиле | `~/Library/Application Support/Tolk/style.key`, права 0600 |
| Pid-файл сервера подсказок | `~/Library/Application Support/Tolk/llama-server.pid` |
| Модели подсказок | `~/Library/Application Support/Tolk/models/*.gguf` |
| Журнал приложения | `~/Library/Logs/Tolk/tolk.log` (набранного текста в нём нет) |
| Журнал сервера подсказок | `~/Library/Logs/Tolk/llama-server.log` |
| Отчёты о падении | `~/Library/Logs/Tolk/crash-*.txt` |

Ключ `style.key` лежит в файле, а не в «Связке ключей»: с самодельным сертификатом «Связка» привязывала «Всегда разрешать» к конкретной сборке, и после каждой пересборки просила пароль. Старый ключ из «Связки» Tolk один раз переносит в файл. Кнопка «Удалить выученное…» стирает `style.db` и ключ.

Файл правил устроен так:

```markdown
## Стиль
- Контекст: рабочая переписка. Пиши живо и коротко.
- Не меняй: числа, даты, ссылки, названия.

## Глоссарий EN → RU
- feed → фид; zone → зона
- whitelist / blacklist → вайтлист / блэклист
```

Раздел о стиле попадает в каждый запрос целиком. Из глоссария берутся только строки, термины которых встретились в тексте. Глоссарий удобнее редактировать на странице «Глоссарий» (⌘5).

## Проверка из командной строки

Из папки проекта:

```
swift run tolk-cli --self-test                    # встроенные проверки движка, без модели и сети
swift run tolk-cli --to en "Привет, как дела?"    # перевод из командной строки
swift run tolk-cli --show-rules --to ru "text"    # какие правила попадут в запрос
swift run tolk-cli --ac-stats                     # статистика автодополнения
curl http://127.0.0.1:8178/health                 # сервер подсказок отвечает (когда автодополнение включено)
```

Остальные режимы (`--rewrite`, `--variants`, `--compose`, `--check`, `--trap-corpus` и другие) перечислены в `swift run tolk-cli --help`.

## Известные ограничения

- Клиента под Windows и Linux нет.
- Модель по облачному API не поддерживается.
- Одна большая модель на сервер: смена модели означает перезагрузку на 30–150 секунд. Два слота Ollama делят все запросы: перевод, сноски, обратный перевод, варианты.
- Если сервер выключен, остаётся только запасной перевод. «Перевод при наборе» запасного пути не имеет: при недоступном сервере он молчит, и текст никуда не уходит.
- Автодополнение выключено по умолчанию. Окончания русских слов посреди слова оно угадывает слабо: на 54 случаях 9 из 15 с исправлением «token healing».
- Живой перевод при наборе не пересматривает ранние предложения, если поздний текст меняет их смысл. Нажмите ⌘↩, чтобы перевести всё заново.
- Редактор иногда меняет стиль там, где не нужно. Тоны «Составить» на коротких тезисах получаются похожими.
- Качество перевода измерялось на русском, украинском и английском. Для других языков замеров нет.
- Приложение подписано самодельным сертификатом: готовая сборка с чужого Mac потребует ручного разрешения.
