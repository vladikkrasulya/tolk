# Tolk: что это и как запустить у себя

Tolk — переводчик в духе DeepL, который работает на своей языковой модели. Выделил текст, дважды нажал ⌘C — рядом с курсором появляется перевод. Переводит с учётом ваших правил и глоссария, умеет отвечать собеседнику на его языке, переводить область экрана и документы.

Состояние на 10.11.2026, версия 0.6.1.

## Сначала главное: какие есть варианты

Система состоит из двух частей: **приложение** (окна, горячие клавиши) и **модель** (собственно перевод). Их можно сочетать по-разному.

| Вариант | Приложение | Модель | Состояние |
|---|---|---|---|
| 1. Локальная модель | Tolk на Mac | Ollama на этом же Mac или на другом компьютере в домашней сети (Windows, Linux, Mac) | Работает, так устроено у автора |
| 2. Модель по API | Tolk на Mac | Облачный сервис с API, совместимым с OpenAI | Пока не сделано, нужна доработка (см. ниже) |
| 3. Только Windows | Приложения нет | Ollama на Windows | Модель запустится, но Tolk под Windows не существует |

Что из этого следует:

- **Есть Mac** — можно пользоваться уже сейчас по варианту 1. Модель может стоять на любом компьютере с достаточной памятью, в том числе на ПК с Windows.
- **Есть только Windows** — сам Tolk не запустится: окна, двойное ⌘C и вставка текста написаны под macOS. На Windows сегодня можно поднять только модель и обращаться к ней через сторонний чат-клиент или скрипт. Клиент под Windows нужно писать отдельно.
- **Нет подходящего железа для модели** — нужен вариант 2, а он в Tolk ещё не реализован.

## Из чего состоит система

```
 Tolk (Mac)                                Сервер модели (любой компьютер)
 ┌──────────────────────────┐   HTTP    ┌──────────────────────────────┐
 │ двойное ⌘C, окна, история │ ───────▶ │ Ollama, порт 11434            │
 │ правила и глоссарий       │ ◀─────── │ модель gemma-translate        │
 └──────────────────────────┘  перевод  └──────────────────────────────┘
        │ если сервер недоступен
        ▼
 запасной путь: Google, перевод Apple на устройстве или ничего
```

- **Приложение Tolk.** Собирает запрос (текст, тон, правила, подходящие строки глоссария), отправляет модели и показывает ответ по мере поступления.
- **Сервер модели.** Ollama с моделью `gemma-translate` (Gemma 4 26B). Tolk обращается к нему по адресу из настроек.
- **Правила и глоссарий.** Обычные текстовые файлы Markdown в папке `~/Translate`: раздел о стиле и строки вида `- термин → перевод`. Можно завести несколько профилей, например «Работа» и «Дом».
- **Запасной путь.** Если сервер не отвечает, Tolk может перевести через Google (текст уходит в интернет), через встроенный перевод Apple (остаётся на устройстве, нужна macOS 26) или не переводить вовсе.

## Что нужно

Для приложения:

- Mac с macOS 14 или новее.
- Инструменты командной строки Swift 6.2 (`xcode-select --install`). Xcode не нужен.

Для модели (вариант 1):

- Компьютер с Ollama. Файл модели занимает 18,7 ГБ.
- Память: примерно 24 ГБ свободной в сумме (видеопамять плюс оперативная). Это оценка по размеру файла, а не замер.
- Чем больше модели помещается в видеокарту, тем быстрее. Для ориентира: у автора видеокарта на 6 ГБ, модель частично считается на процессоре, один текст переводится в среднем за 6 секунд.

## Вариант 1. Локальная модель

Шаги одинаковы для Windows, Linux и Mac. На Windows они не проверялись заново при написании этого документа — так модель была установлена на сервере автора.

1. Установите Ollama с сайта ollama.com.
2. Скачайте базовую модель:

   ```
   ollama pull gemma4:26b
   ```

3. Создайте файл `Modelfile` с таким содержимым:

   ```
   FROM gemma4:26b
   SYSTEM You are a professional translator. Translate the user text accurately and naturally, preserving meaning, tone, formatting, code and names. Output only the translation, with no explanations.
   PARAMETER num_ctx 32768
   PARAMETER num_predict 8192
   PARAMETER temperature 0.3
   PARAMETER top_k 64
   PARAMETER top_p 0.95
   ```

4. Соберите из него модель для перевода:

   ```
   ollama create gemma-translate -f Modelfile
   ```

   Имя должно заканчиваться на `-translate`: в настройках Tolk в списке моделей показываются только такие.

5. Если модель стоит не на том же компьютере, что Tolk, разрешите Ollama принимать запросы из сети: задайте переменную окружения `OLLAMA_HOST=0.0.0.0` и перезапустите Ollama. Откройте порт 11434 в брандмауэре только для домашней сети.
6. Необязательно: `OLLAMA_NUM_PARALLEL=2`, чтобы два перевода шли одновременно.
7. Проверьте с компьютера, где будет Tolk:

   ```
   curl http://АДРЕС_СЕРВЕРА:11434/api/tags
   ```

   В ответе должна быть `gemma-translate`.

Что стоит знать:

- Первый запрос после запуска или смены модели идёт долго, от 30 до 150 секунд: модель загружается в память.
- У модели по умолчанию включено «размышление», с ним ответ занимает около минуты. Tolk сам его отключает. Если проверять модель командой `ollama run`, будет медленно — это не поломка.

## Вариант 2. Модель по API

Сейчас в Tolk этого нет. Что уже есть и чего не хватает:

- Tolk общается с моделью по протоколу, совместимому с OpenAI (`/v1/chat/completions`), так что сам формат запросов подойдёт большинству облачных сервисов.
- Не хватает: поля для ключа API в настройках, ручного ввода имени модели (сейчас список берётся у Ollama) и отключения прогрева модели, который есть только у Ollama.
- В настройках есть «удалённый адрес» с дополнительными заголовками, но он рассчитан на тот же Ollama за туннелем. С облачным API он не проверялся.

Чем этот вариант отличается для пользователя:

- Не нужно мощное железо, работает откуда угодно.
- Тексты уходят стороннему сервису.
- Оплата по расходу, нужен свой ключ.

## Установка Tolk на Mac

1. Получите исходный код проекта.
2. Один раз создайте локальный сертификат подписи, чтобы после пересборки не слетало разрешение «Универсальный доступ»:

   ```
   scripts/make-signing-cert.sh
   ```

   macOS может спросить пароль от учётной записи.

3. Соберите и установите:

   ```
   scripts/build-app.sh
   scripts/install.sh
   ```

   Приложение попадёт в `/Applications/Tolk.app` и будет запускаться при входе в систему. Без автозапуска: `scripts/install.sh --no-autostart`.

4. При первом запуске выдайте разрешения в «Системных настройках → Конфиденциальность и безопасность»:
   - «Универсальный доступ» — для двойного ⌘C и вставки перевода;
   - «Запись экрана» — только если нужен перевод области экрана.

5. Откройте настройки Tolk и укажите:
   - адрес сервера модели (по умолчанию стоит адрес сервера автора, `http://192.168.1.13:11434`, его нужно заменить на свой; для модели на этом же Mac — `http://localhost:11434`);
   - модель `gemma-translate`;
   - запасной путь. По умолчанию это Google: когда сервер недоступен, текст уйдёт в Google. Если это нежелательно, выберите перевод Apple или «нет».

Приложение подписано самодельным сертификатом. Оно собирается на своём Mac; готовую сборку с чужого компьютера macOS будет блокировать.

## Файлы и настройки

| Что | Где |
|---|---|
| Настройки | `~/Translate/tolk.json` (всё меняется и через окно настроек) |
| Правила профиля «Работа» | `~/Translate/rules.md` |
| Правила профиля «Дом» | `~/Translate/home.md` (если файла нет, действуют встроенные правила) |
| История переводов | хранится локально, до 3000 записей |
| Журнал | `~/Library/Logs/Tolk/tolk.log` |

Файл правил устроен так:

```markdown
## Стиль
- Контекст: рабочая переписка. Пиши живо и коротко.
- Не меняй: числа, даты, ссылки, названия.

## Глоссарий EN → RU
- feed → фид; zone → зона
- whitelist / blacklist → вайтлист / блэклист
```

Раздел о стиле попадает в каждый запрос целиком. Из глоссария берутся только строки, термины которых встретились в переводимом тексте.

## Проверка без окон

Из папки проекта:

```
swift run tolk-cli --self-test            # встроенные тесты движка
swift run tolk-cli --to en "Привет, как дела?"   # перевод из командной строки
swift run tolk-cli --show-rules --to ru "text"   # какие правила попадут в запрос
```

## Известные ограничения

- Клиента под Windows и Linux нет.
- Модель по API не поддерживается (см. вариант 2).
- Одна большая модель на сервер: смена модели означает перезагрузку на 30–150 секунд.
- Автодополнение при наборе выключено и в текущем виде включать его не рекомендуется.
- Качество перевода измерялось на русском, украинском и английском; для других языков замеров нет.
